# Patch Requirements

本ドキュメントでは、オリジナルのリポジトリ
https://github.com/bearcove/tracey
に対して変更を加えた内容について記載する。



## r[req.markdown.section.support]
`#`から始まる要件記述のをサポートする。
#はマークダウンのHeadingsに使われる記法であり、その中にr[req.xxx]のような記載ができるようになる。
この記法では複数行の入力もサポートし、#の数が同じ、または1つ上の#が出てくるまでを要件の範囲とする。

オリジナルのtraceyは

```
## r[req.run]
起動できる

```

のような ## で始まる要件を読み取らない。

また、複数段落（空行を挟んだ要件）を読み取らない。
複数行にまたがる要件は

```
> r[req.exit]
> CTRL+Cで終了できる。
>
> または終了ボタンで終了できる。

```

のようにすべての行頭に>を付ける必要がある。


そのため、`#`から始まるマークダウン記法で要件を記載することができるように変更を行う。

サポートする記法は以下のようになる


```
### r[req.type.a]
aとタイプしたらAと入力される

### r[req.type.numbers]
数字を入力したら、数字が入力される

- 777 と入力した場合は、特別にLuckyと入力する
- 222 と入力した場合は、特別にCatと入力する

### r[req.type.others]
その他の入力(数字と英数字以外)に対しては、特別な処理を行わない。


## 他の仕様

### r[req.other.example]
他の仕様の例

- こんな仕様

### r[req.other.another_example]
別の仕様の例

```


上記の例のように、「# から始まる要件の記法」をサポートする。それと同時に「# から始まる要件は複数行の入力をサポートする」。
要件記述は同じレベルの#、または上のレベルの#が出てくるまでを複数行の範囲とする。
つまり#2つで要件を記載している場合は、##2つか、#1つが出てきたら区切りとする。
#の数は任意の数で利用でき、その数と同じ、または1つ上の#が出てくるまでを要件の範囲とする。
